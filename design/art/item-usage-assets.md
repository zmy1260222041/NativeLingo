# 物品资产规格 — 第一轮可玩实现

来源 FR-44 / item-usage。日期 2026-09-06。

复用已有 `prp_market_burger_v01`、`prp_market_wrap_v01`、`prp_market_drink_v01`：分别覆盖夹馅食物、其他包裹食物、饮品的首轮投影。
具体品名始终由交互标签辨别，共用轮廓不将不同物品效果混同。旧食物复用 wrap；打包态显示独立包裹底座。
毯子采用折叠/铺开两态布面；零件采用双联金属块；电池采用成对柱形。三者使用程序化占位表现，后续替换美术不改变稳定 ID。
交付位在店员顾客侧，住处位置设在可到达的入口平台及紧邻维修设备处，不把物品埋入建筑基座。
场景切换只重建投影；安装与使用改变可见位置/数量/设施状态，无奖励光柱。动作音与短动作由提交后的事件触发，取消无完成音。
本轮资产共用是功能实现，不宣称完成独立逐件最终美术验收。

界面类别图形使用 32 px 程序化墨线：食物为开口种荚、饮品为瓶形、住所用品为承托槽。三者轮廓在灰阶下
仍不同，语义色仅作冗余；后续若收入共享 UI 图集，必须保持相同轮廓与 2.25 px 以上描边，不改交互含义。
