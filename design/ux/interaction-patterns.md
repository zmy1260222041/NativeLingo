# 《异乡人 / Stranger》交互模式库

> **状态**：Approved / Implemented for Vertical Slice
> **作者**：用户 + Codex Game Studios UX Designer
> **最后更新**：2026-08-10
> **模板**：Interaction Pattern Library
> **适用范围**：纵向切片 gameplay HUD、语音/手势交互与全屏反馈

---

## 概览

本模式库把《异乡人》的核心原则转为可重复实现的交互规则。所有模式都要求：UI 不拥有
游戏状态；输入通过语义 action；语言表达失败不产生关系或生存惩罚；键鼠与手柄功能对等；
动态与颜色都有非动态、非颜色替代。

模式 ID 是稳定引用。视觉样式可以在 Art Bible 阶段变化，但输入语义、状态、反馈优先级和
无障碍约束不得在没有 UX 评审的情况下改变。

## 通用规则

1. **动作先于设备**：实现和文案引用 `interact`、`gesture`、`push_to_talk` 等 action，不引用物理键码。
2. **一个位置一个职责**：中心下方只能有临近互动条或语音会话卡，两者互斥。
3. **世界反馈优先**：NPC 表演、实物变化和环境状态是结果主反馈；HUD 只确认玩家可能遗漏的事实。
4. **失败可恢复**：任何错误状态必须说明发生了什么、玩家下一步能做什么、是否有损失；语言错误明确无损失。
5. **颜色不单独编码**：状态必须同时使用图标轮廓、文字或形状变化。
6. **动态可替代**：位移、脉冲、擦拭和循环动效都有淡化或静态替代。
7. **不堆叠**：同一事件不得同时触发 objective toast、普通 toast 和大覆盖层三重反馈。

## 模式详规

### P-01 输入提示字形 / Adaptive Action Glyph

**类别**：Input
**使用位置**：临近互动条、语音会话卡、完成覆盖层、确认提示

**说明**：把语义动作显示为玩家当前设备与当前重映射对应的 glyph + 本地化动词。

**规范**：

- 输入设备由最后一次超过有效阈值的输入决定；鼠标微动与摇杆死区噪声忽略。
- 切换设备后 100 ms 内更新全部可见 glyph，采用一次交叉淡化，不并排显示两套提示。
- 键盘键帽显示重映射后的可读名称；手柄 glyph 使用已识别品牌，未知品牌使用通用位置图标。
- glyph 后必须有动作词，如 `[LB] 按住说话`；仅显示字母不满足可理解性要求。
- 同一 action 绑定多个键时显示首选绑定；设置页可查看完整绑定。
- glyph 至少 24×24 参考像素，和文字基线对齐；高对比模式增加外框。

**何时使用**：任何需要玩家立即执行的 gameplay 或 overlay 操作。
**何时不用**：纯说明性文本、已完成结果或不会响应输入的状态。

**无障碍**：不使用颜色区分设备；支持 80%–150% UI Scale；Toggle-to-Talk 模式把“按住”改为“按下开始/再次按下发送”。

---

### P-02 临近交互条 / Contextual Proximity Prompt

**类别**：Input / Overlay
**使用位置**：NPC、采集物、加热器、蓄水器、庇护所

**说明**：当玩家进入最近有效对象的交互范围时，在中心下方显示对象身份和最多三个动作。

**规范**：

- 同时只绑定一个最近且可见目标；目标需稳定 120 ms，离开需 150 ms 防抖。
- 第一行显示名称；第二/三行按优先级显示动作。
- NPC 动作顺序：说话、手势、观察；普通物体通常只有互动。
- 最多三个动作。更多动作必须进入独立情境菜单，不能压缩字号硬塞。
- 开始 P-03 后，本模式被语音会话卡替换；结果返回或取消后才恢复。
- 目标失效、隐藏或离开范围立即撤销可执行 action。

**何时使用**：距离和上下文决定可用性的世界交互。
**何时不用**：全局 action、菜单按钮、需要浏览多个项目的选择列表。

**无障碍**：目标名称和动作必须是文字，不只靠世界轮廓；提示出现不要求精确鼠标瞄准。

---

### P-03 按住说话 / Hold-to-Speak

**类别**：Input
**使用位置**：关键 NPC 请求、交易、求助和协商

**说明**：默认按住 action 录音、松开发送，以身体动作保持交流节奏；同时提供 Toggle-to-Talk 无障碍变体。

**规范**：

- 只有有效 NPC 目标存在时才能开始；无目标时给出中性提示，不启动麦克风。
- 按下后立即进入 P-04 Listening；松开后若音频有效则进入 Transcribing。
- `Esc/B` 取消本次录音，不上传、不改变任务、需求、关系或目标。
- 音频短于服务协议下限时进入 P-05，不叫作失败。
- 最长录音 15 秒；12 秒开始以文字显示剩余时间，15 秒自动结束并进入转写。
- 离开交互范围时取消录音。转写请求携带固定 `target_id`，不在返回时重新读取最近目标。
- Toggle 模式：第一次按下开始，第二次按下发送；取消和手势 action 不变。

**何时使用**：玩家需要真实开口、且语境已经由世界提供的高价值交流。
**何时不用**：普通拾取、移动、频繁重复操作、无 NPC 接收者的语言练习。

**无障碍**：麦克风永远可选；P-05 手势路径产生等价任务/关系结果。录音状态始终有视觉文本。

---

### P-04 聆听与转写状态 / Listening & Transcription

**类别**：Feedback
**使用位置**：语音会话卡

**说明**：将“设备正在录音”和“服务正在理解”明确分开，防止玩家重复按键或怀疑游戏没有响应。

**规范**：

| 状态 | 必需内容 | 动态 | 下一步 |
|---|---|---|---|
| Listening | 麦克风图标、“正在听”、计时、NPC 名称 | 可选低幅波形 | 松开发送、取消、手势 |
| Transcribing | 时钟/点列图标、“正在理解” | 可选三点序列 | 取消等待；超时进入 P-05 |
| Transcript Available | `听到：“原始英语”` | 交叉淡化 | 等待意图结果或进入 P-05 |
| Understood | 勾形/开放手势图标、“对方听懂了” | 一次性确认 | 返回世界反馈 |

- 不展示伪造的识别进度百分比。
- 原始转写不得自动纠正、翻译或以绿色高亮“正确单词”。
- Understood 表示意图传达，不表示发音或语法满分。
- 语音卡出现时延后非紧急 toast，避免两个文本源竞争。

**何时使用**：所有异步语音请求。
**何时不用**：同步手势或普通世界互动。

**无障碍**：减弱动态模式用静态图标和文字；所有状态不依赖监听音、震动或颜色。

---

### P-05 无惩罚澄清 / Non-Punitive Clarification

**类别**：Recovery
**使用位置**：没听清、音频过短、权限拒绝、服务离线、超时

**说明**：在不评价玩家能力的前提下说明系统没有得到可靠意图，并提供三条可恢复路径。

**规范**：

- 标题使用“没听清，没关系”或“麦克风暂不可用”，禁止“回答错误”“发音失败”“0 分”。
- 若有转写，显示 `听到：“…”`；若没有，不显示空引号。
- 动作按情境显示：`再说一次`、`用手势`、`取消`。服务离线时手势为第一动作。
- 明示“不会损失关系/可以免费重试”的文案只在首次澄清或连续两次不确定时出现，避免唠叨。
- 同一会话连续三次不确定后，默认焦点移到手势，但不禁止继续说。
- 不修改任何任务、生存、资源、关系和存档字段。

**何时使用**：系统不确定或语音链路不可用。
**何时不用**：玩家明确拒绝 NPC、资源不足或任务条件不满足；这些是正常领域结果。

**无障碍**：手势是完整替代而非降级奖励；文案避免羞辱、诊断和技术错误码，详细错误只进开发日志。

---

### P-06 结果反馈条 / Outcome Toast

**类别**：Feedback
**使用位置**：拾取、保存、轻量任务结果、关系行为确认、非阻断警告

**说明**：顶部居中的短时反馈，确认玩家已触发某个事件，但不取代世界变化或关键覆盖层。

**规范**：

- 同时一条，队列最多两条；超出后按优先级合并或丢弃最低优先级重复项。
- Good/Neutral 停留 3.2 秒，Warning 6 秒；关键错误必须等待明确动作或转入覆盖层。
- 600 ms 内同类型拾取合并数量。
- 图标 + 文案 + 边框形态共同区分 good/neutral/warning。
- 语音会话中非紧急 toast 延后；日切/完成前清理队列。
- 不提供可点击操作；需要操作时使用 P-05 或模态层。

**何时使用**：玩家无需立即做决定的短时确认。
**何时不用**：任务终点、重置确认、权限选择、语音澄清、持续危险。

**无障碍**：消息可由“延长 UI 消息”设置变为 6/10 秒；重要信息不得仅自动消失一次。

---

### P-07 目标卡 / Objective Card

**类别**：Data Display
**使用位置**：左上 HUD

**说明**：持续表达当前意图，更新时短时展开；不把聚落变成任务清单。

**规范**：

- 日时标记与目标卡组成一个视觉簇。
- 默认目标最多两行；最小窗口/大字模式允许三行。
- 数量目标在同一卡中显示 `1/2` 或实物刻度，不建立常驻资源栏。
- 完成时先显示勾形 + “完成”300–600 ms，再切换新目标。
- 新目标展开 3.5 秒后收拢；录音时推迟展开。
- 没有目标时显示世界导向意图或隐藏正文，不显示空数据。

**何时使用**：一个清晰的当前主要意图。
**何时不用**：多任务追踪、日志、地图标记或关系故事回顾。

**无障碍**：目标更新同时有文字与一次非刺耳提示音；大字模式不能截断关键动词和目标名。

---

### P-08 生存需求计 / Survival Need Meter

**类别**：Data Display
**使用位置**：左下 HUD

**说明**：以稳定顺序和多重编码呈现食物、温暖、精力，紧迫但不制造持续噪声。

**规范**：

- 顺序固定：食物、温暖、精力。
- 每行有独特图标、标签、填充条与可选百分比；隐藏百分比时仍保留清晰状态。
- 阈值形态：稳定为连续框；注意为单侧缺口框；紧急为双侧尖角框，并出现行动词。
- 越过阈值只播放一次强调；持续衰减只平滑填充，更新视觉限频到 10 Hz。
- 回升越过阈值时使用恢复图标/文案，不重复警告音。
- 0 值本身不执行昏倒；领域系统拥有规则，HUD 只显示投影。

**何时使用**：持续变化且影响每刻决策的少量核心需求。
**何时不用**：短期物品数量、关系、任务进度或隐藏角色属性。

**无障碍**：对比达标；不靠红黄绿；允许百分比开关、高对比模式和 150% UI Scale。

---

### P-09 日切遮罩 / Day Transition

**类别**：Overlay
**使用位置**：庇护所睡眠后进入下一天

**说明**：以短暂、可跳过的情绪转场建立一天的自然停止点。

**规范**：

- 触发后暂停 gameplay 输入与领域时间；不销毁当前场景。
- 显示第 N 天和一句不超过 36 个中文字符的情绪/目标暗示。
- 标准时长约 1.2 秒；300 ms 后任意确认 action 可跳过。
- 关闭时清空对应输入，避免同一确认键触发世界互动。
- 恢复后焦点回 gameplay，不落在隐藏 Control 上。

**何时使用**：明确的日程边界和状态结算。
**何时不用**：普通目标更新、区域跨门、短暂睡眠动作。

**无障碍**：减弱动态使用 200 ms 淡化并可立即跳过；不使用频闪、快速径向缩放或相机运动。

---

### P-10 完成覆盖层 / Completion Overlay

**类别**：Modal
**使用位置**：三日纵向切片终点

**说明**：在保持世界可辨认的情况下承接情绪结局，并给出继续观察或重新开始的明确选择。

**规范**：

- 覆盖层出现时暂停 gameplay 输入，背景遮罩 alpha 0.55–0.68。
- 层级：情绪结论 → 关系回报 → 切片完成标识 → 操作。
- 默认操作“继续留在聚落”；次操作“重新开始三日切片”。
- 重开需二次确认；取消等同返回/继续，不直接退出或清档。
- 使用 P-11 管理焦点，鼠标、键盘和手柄功能对等。
- 不自动关闭、不用 toast 代替、不强制社交分享或评分。

**何时使用**：重要且不可忽略的会话/版本完成节点。
**何时不用**：普通日终、任务完成或轻量关系变化。

**无障碍**：支持减弱动态、UI Scale 150%、字幕式完整文本和清晰焦点环。

---

### P-11 覆盖层焦点 / Overlay Focus Trap

**类别**：Navigation
**使用位置**：完成层、重置确认、未来设置/暂停层

**说明**：模态层打开时把键盘/手柄导航限制在有效控件中，关闭后恢复之前上下文。

**规范**：

- 打开前记录来源上下文；默认焦点放在最安全、可逆的操作。
- 导航顺序遵循视觉从上到下、从左到右；方向键、D-pad、左摇杆和 Tab 可遍历。
- 焦点到边界时循环到同组首尾，不能进入遮罩后的 HUD。
- 焦点环与背景至少 3:1，不能只靠轻微色变。
- Esc/B 执行明确的取消/返回；重置等破坏性动作需要二次确认。
- 关闭后恢复 gameplay 输入或原控件；吞掉用于关闭的同帧 action。

**何时使用**：任何阻断 gameplay 且包含选择的覆盖层。
**何时不用**：toast、临近提示、非交互日切文字阶段。

**无障碍**：所有控件有可读名称和状态；不需要精确鼠标；焦点不可消失。

## 模式组合规则

| 场景 | 允许组合 | 冲突处理 |
|---|---|---|
| 接近 NPC | P-01 + P-02 | 只显示一个目标和三项以内动作 |
| 开始录音 | P-01 + P-03 + P-04 | P-04 替换 P-02；P-06 非紧急消息延后 |
| 没听清 | P-01 + P-05 | 不额外弹出 warning toast |
| 需求告急且正在说话 | P-04 + P-08 | 需求仅对应行升权；不遮挡会话卡 |
| 目标完成 | P-07 + 可选 P-06 | 同一事实只由目标卡或 toast 主讲一次 |
| 日切 | P-09 | 隐藏 P-02/P-04，清理 P-06 队列 |
| 切片完成 | P-10 + P-11 | 隐藏其他 HUD，背景仅作情绪上下文 |

---

## 待补模式与范围边界

- 暂停/设置界面模式：需要单独 UX spec 后加入。
- 输入重映射冲突解决模式：Enhanced 无障碍等级要求，但属于设置流程。
- 轻量背包/关系回顾：当前 HUD 明确不承载，若进入纵切范围需单独设计。
- 字幕说话人定位与多角色重叠：当前只有一对一关键交流，正式语音内容增加后补充。
- 屏幕阅读器语义桥接：不属于当前 Enhanced 承诺，但 Control 层级需保留稳定可读顺序。

## 验收规则

- [ ] `design/ux/hud.md` 中每个交互元素都引用本目录中的稳定模式 ID。
- [ ] 任意模式实现都不硬编码物理键码或按钮品牌。
- [ ] P-03/P-04/P-05 的每条退出路径都不修改语言惩罚相关领域状态。
- [ ] 模态层全部使用 P-11，默认焦点位于安全可逆操作。
- [ ] 颜色、声音或动态被关闭时，所有核心状态仍可独立理解。
- [ ] 新模式在进入实现完成状态前必须先补到本目录，并通过 UX 复核。
