# 物品交互 UX — FR-44

日期：2026-09-06。规则来源：../gdd/item-usage.md。

柜台成交后显示有名称的实物。靠近并交互打开该柜台的待领清单；每份独立，允许吃一份、打包一份，另提供整批打包按钮。
按住 Tab / RB 打开随身物品，松开关闭；暂停菜单可改为切换模式。方向键/手柄十字键上下选择，E / X 执行主动作，R / 十字键右执行次动作，
Esc / B 取消。按钮均使用 InputMap、显示当前映射、可鼠标点击；物品界面未打开时不截获原有输入。
柜台主动作吃喝、次动作打包；随身主动作吃喝或带回住处；住所界面分为领取箱与床铺/维修位/电力位。
携带日用品在兼容位置主动作为放置；第二次主动作才铺好/安装/使用；次动作收回可收回物品。生效耐用品主动作可停用并留在原位。
T / 十字键左整批打包。左肩键 LB 保留录音，右肩键 RB 才是物品条，不互相占用。
每份显示具体名称、类别、数量/次数、状态和下一步，容量分为 4 消费品位 / 1 住所用品位。没有物品时给出找店员的指引。
溢出时显示一次确认，第二次按同一使用动作确认；取消、切换条目或高优先级事件清除确认。

高优先级：暂停/日切/昏倒/录音/正在进行的服务会话关闭物品界面。世界移动不停时，物品条只拦截其动作键；跳跃、奔跑状态拒绝使用。
距离离开柜台/住所则关闭相应界面，不能远程领取或放置。邻近 NPC 本身不等同已在服务会话，不阻挡领取。
列表使用滚动区，核心动作置底，宽度不超过视口 90%，高度不超过视口 75%；跟随 HUD 字号缩放。
图标、文字、焦点边框共同表达状态；减少动态用静态状态切换，音频关闭时仍有可见反馈。实机验证 1152×648 / 150%。
