# 《异乡人 / Stranger》HUD 设计规范

> **状态**：Approved / Implemented for Vertical Slice
> **作者**：用户 + Codex Game Studios UX Designer
> **最后更新**：2026-08-10
> **模板**：HUD Design
> **目标平台**：PC（macOS 优先，Windows 后续）
> **输入方式**：键盘/鼠标与手柄完全覆盖
> **参考画布**：1440 × 900；最小支持窗口 1152 × 720
> **无障碍等级**：Enhanced，详见 `design/accessibility-requirements.md`

---

## 设计上下文与约束

HUD 服务于第三人称社交生存，而不是语言练习界面。玩家大部分时间观察世界、规划路线、
移动和收集；只有靠近关键 NPC 时才进入语音或手势交流。任何语音失败都必须保持中性，
并清楚提供免费重试与手势出口。

当前没有 `design/player-journey.md`，因此以下情绪上下文来自已批准的游戏概念：玩家从谨慎、
饥饿和陌生感出发，经由行动与表达逐渐获得安全与归属。视觉实现遵循
`design/art/art-bible.md`；本规范锁定信息层级、空间、状态、动效边界和可访问性，并与
Art Bible 的配色、形状和动画语言共同约束当前 HUD。

### 设计支柱映射

| 游戏支柱 | HUD 响应 |
|---|---|
| 先行动，后开口 | 探索时不显示语言教学面板；只在可交流 NPC 附近出现表达选项 |
| 生存有压力，表达无羞耻 | 生存需求可告警；语音失败不使用红叉、扣分、失败音或倒计时惩罚 |
| 关系就是生存资源 | 关系结果优先由 NPC 表演和世界变化表达；HUD 只做短时确认 |
| 成长必须在世界中可见 | HUD 不以经验条替代角色、区域和他人态度的变化 |
| 小聚落，深模拟 | 不加入小地图和任务问号墙；目标只说明当下意图，不替玩家规划路线 |

## HUD 哲学

**自适应极简：生存状态常驻，任务与交流按情境展开，世界表演优先于文字说明。**

HUD 默认只维持两个永久信息簇：当前日程/目标和三项生存需求。接近可交互对象、需求越过
阈值、目标更新或语音会话开始时，相关信息暂时展开；情境结束后恢复安静状态。HUD 不显示
常驻游戏标题、常驻教学键位、准星、小地图、经验条或关系数字。

### 注意力顺序

1. **中心世界与角色表演**：任何 HUD 不遮挡玩家、当前 NPC、玩家前方 20% 的导航区域。
2. **紧急生存状态**：只有越过阈值时才升高视觉权重。
3. **当前互动**：靠近 NPC 或物体时在中心下方出现，可由余光读取。
4. **当前目标**：目标变化时展开，随后收拢为一至两行。
5. **系统确认**：拾取、保存、关系和服务状态以短时 toast 呈现。

| 三日切片完成 | Contextual | P0 | 纵切终点 | 取得焦点的完成覆盖层 |
| 浆果、零件、水总数 | On Demand | P2 | 只在相关目标/交互中影响决策 | 目标进度或物体反馈，不常驻 |
| NPC 关系数值 | Hidden | P2 | 关系应由行为而非量表表达 | 不显示数字；只显示世界反馈 |
| NPC 记忆文本 | On Demand | P3 | 后续日志/关系页范围 | 当前 HUD 不承担 |
| 完整操作帮助 | On Demand | P2 | 首次教学或暂停设置 | 首次情境提示；不常驻底栏 |
| 游戏标题 | Hidden | P3 | 不影响每刻决策 | 只用于启动、暂停和完成画面 |

### 冲突检查

Must Show 只有两个信息簇和五个短值（日时、目标、三项需求），与“自适应极简”相符。
资源数量只嵌入相关目标，避免当前原型把教学、目标和状态同时铺满屏幕。

## 安全区与响应式规则

### Safe Frame

- 所有 HUD 使用居中的 **Safe Frame**，世界渲染仍铺满窗口。
- 16:9、16:10 与更窄比例：Safe Frame 等于视口。
- 宽于 16:9：Safe Frame 宽度固定为 `viewport_height × 16/9` 并水平居中，避免 HUD 被推到超宽屏边缘。
- 水平内边距：`clamp(Safe Frame 宽度 × 0.04, 24 px, 72 px)`。
- 垂直内边距：`clamp(viewport_height × 0.04, 24 px, 48 px)`。
- 系统安全区、窗口刘海或平台保留区比上述值更大时，取系统值。

### 分辨率与缩放

| 情况 | 规则 |
|---|---|
| 1152 × 720 最小窗口 | 目标卡宽 360 px；提示卡宽不超过 600 px；正文实际像素不低于 16 px |
| 1440 × 900 参考 | 使用本规范标称尺寸 |
| 1920 × 1080 / 2560 × 1440 | 几何按 UI Scale 缩放，不按分辨率无限放大；卡片最大宽度不变 |
| 21:9 / 32:9 | 使用 16:9 Safe Frame；中心提示仍以视口中心对齐 |
| 窗口宽度不足 1152 | HUD 进入 Compact：目标最多三行、需求仅图标/短条/数值，互动动作纵向排列 |
| UI Scale 80%–150% | 布局重新流动，不能仅放大后裁切；150% 时提示动作最多每行两个 |

支持测试矩阵：1152×720、1280×720、1440×900、1920×1080、2560×1440、2560×1080。

## HUD 元素

### 元素总表

| 元素 | 分类 | 内容 | 更新 | 使用模式 | 动效 |
|---|---|---|---|---|---|
| 日时标记 | Must Show | 第 N 天、世界时间 | 事件/每游戏分钟 | P-07 目标卡 | 时间数字不逐帧跳动 |
| 目标卡 | Must Show | 当前目标、可选进度 | 任务事件 | P-07 目标卡 | 更新时展开，完成后勾选并换项 |
| 生存需求簇 | Must Show | 食物、温暖、精力 | 最大 10 Hz；显示平滑 | P-08 生存需求计 | 阈值变化一次性强调 |
| 临近互动条 | Contextual | 名称、1–3 个动作 | 目标变化事件 | P-02 临近交互条、P-01 输入提示字形 | 120 ms 淡入/淡出 |
| 语音会话卡 | Contextual | 录音、转写、结果、替代 | 语音适配器事件 | P-03、P-04、P-05 | 状态间交叉淡化 |
| 反馈 toast | Contextual | 拾取、保存、结果、警告 | 领域事件 | P-06 结果反馈条 | 180 ms 进入，按严重性停留 |
| 日切覆盖层 | Contextual | 新日、短目标暗示 | 日切事件 | P-09 日切遮罩 | 可跳过，减弱动态替代 |
| 完成覆盖层 | Contextual | 结局句、下一步操作 | `run_completed` | P-10 完成覆盖层、P-11 覆盖层焦点 | 一次进入，不循环 |

### 日时与目标卡

- 不在游戏中常驻显示“异乡人 / STRANGER”标题。
- 日时标记一行显示，时间由领域层提供格式化投影；HUD 不自行推导时间。
- 目标卡默认显示“目标”短标签和最多两行目标文本；相关数量以 `1/2` 或两枚实物刻度显示。
- 目标改变时展开 3.5 秒，旧目标显示勾选图标与文字“完成”，再替换为新目标。
- 无有效目标时显示探索意图，不显示空白框或“NULL”。纵切完成后由完成覆盖层接管。

### 生存需求簇

- 顺序固定：食物、温暖、精力，避免扫视位置变化。
- 每项包含独特图标、文字标签、十段式/连续填充条和可选百分比；颜色不是唯一信号。
- 默认使用低对比表面和完整数值。设置允许隐藏百分比，但图标、条与阈值文字必须保留。
- 阈值：`>50` 稳定；`26–50` 注意；`1–25` 紧急；`0` 触发领域层昏倒流程。
- 进入注意状态时，需求行展开并显示行动词（“找食物”“靠近热源”“休息”）；进入紧急状态时增加独特边框形状和一次性提示音/震动。
- 数值持续衰减时只平滑更新填充，不逐帧闪烁、跳字或播放循环音。

### 临近互动条

- 仅在最近有效目标位于交互距离内时显示；目标离开范围后保留 150 ms 防抖再淡出。
- 第一行是对象名称；NPC 可在名称后显示关系语气词（如“谨慎”“熟悉”），不显示关系数字。
- 第二/三行最多三个动作，按当前输入设备显示 glyph + 动词。
- NPC 默认动作优先级：按住说英语 → 手势 → 观察；普通物体只显示互动。
- 同时存在多个对象时仍只显示一个目标，不堆叠提示；目标切换需要稳定 120 ms。

### 语音会话卡

语音会话卡替换临近互动条，而不是叠在其上。状态详见“语音状态机”。录音时必须显示：

- 明确文字“正在听”与麦克风图标；
- 已录时长，15 秒上限前 3 秒显示剩余提示；
- “松开发送”与“取消”；
- 手势替代入口；
- 当前 NPC 名称，避免玩家不知道在对谁说话。

### 反馈 Toast

- 顶部居中，一次一条；最多保留两条队列，同类拾取在 600 ms 内合并为“蓝莓果 ×2”。
- Good：勾形/星芒图标；Neutral：圆点/信息图标；Warning：三角形图标。三类使用不同文案和边框，不只换颜色。
- Good/Neutral 默认 3.2 秒，Warning 6 秒；鼠标悬停、键盘焦点或读取设置可延长。
- 不把语音未识别叫作“失败”；文案使用“没听清，没关系”“可以再说一次或用手势”。
- 任务完成、昏倒、日切与纵切完成不依赖自动消失 toast 作为唯一通知。

## 动态行为

### HUD 密度规则

| 游戏状态 | 目标卡 | 需求簇 | 中心下方 | Toast |
|---|---|---|---|---|
| 普通探索 | 收拢 | 常驻低权重 | 无 | 按事件 |
| 接近普通物体 | 收拢 | 常驻 | 临近互动条 | 按事件 |
| 接近 NPC | 收拢 | 常驻 | NPC 三动作互动条 | 按事件 |
| 录音/转写 | 一行收拢 | 降低对比，紧急项除外 | 语音会话卡 | 非紧急 toast 延后 |
| 需求进入紧急 | 收拢 | 对应项展开 | 当前交互保留 | 紧急提醒仅一次 |
| 目标更新 | 展开 3.5 秒 | 常驻 | 若正在录音则延后展开 | 目标完成 toast 合并进卡 |
| 日切 | 隐藏 | 隐藏 | 隐藏 | 清队列后显示覆盖层 |
| 完成 | 隐藏 | 可选淡化 | 隐藏 | 清队列后显示完成覆盖层 |

### 语音交互状态机

```text
Idle / 临近 NPC
  ├─ 按住 Push-to-Talk ─→ Listening
  │                         ├─ 松开且有有效音频 ─→ Transcribing
  │                         ├─ 取消 ────────────→ Idle（无结果、无惩罚）
  │                         └─ 音频设备错误 ────→ Unavailable
  ├─ Gesture ─────────────→ Gesture Confirmed → Idle
  └─ 离开范围 ────────────→ Hidden

Transcribing
  ├─ 意图接受 ────────────→ Understood → NPC 世界反馈 → Idle
  ├─ 不确定/音频过短 ─────→ Clarify → Retry / Gesture / Cancel
  └─ 服务错误/超时 ───────→ Unavailable → Gesture / Retry Later / Cancel
```

| 状态 | 标题 | 辅助信息 | 可用动作 | 禁止反馈 |
|---|---|---|---|---|
| Listening | 正在听 | 计时、NPC 名称 | 松开发送、取消、手势 | 成绩、正确率、红色错误 |
| Transcribing | 正在理解 | 可显示已录时长；收到文本后显示原始英语 | 取消等待；超时后手势 | 假进度百分比 |
| Understood | 对方听懂了 | “听到：…”与 NPC 回应 | 继续 | 语法打分 |
| Clarify | 没听清，没关系 | 原始转写（如有）、原因的友好说明 | 再说一次、手势、取消 | 扣关系、失败音 |
| Unavailable | 麦克风暂不可用 | 权限/服务的可行动说明 | 使用手势、稍后重试、取消 | 阻断任务 |
| Gesture Confirmed | 对方看懂了手势 | 提醒英语可随时免费重试 | 继续 | 把手势描述为较差答案 |

离开 NPC 交互范围时：Listening 自动取消且不上传；Transcribing 的结果可以返回，但若目标已失效，
只显示中性系统确认，不改变错误目标。目标身份必须跟随请求携带，不能依赖“当前最近 NPC”。

## 平台与输入变体

### 输入映射

| 语义动作 | 键鼠默认 | 手柄默认（Xbox / PlayStation） | HUD 文案 |
|---|---|---|---|
| 互动/观察 | E | X / □ | `[glyph] 观察` 或 `[glyph] 互动` |
| 按住说话 | V（按住） | LB / L1（按住） | `[glyph] 按住说话` |
| 手势 | G | Y / △ | `[glyph] 手势` |
| 取消 | Esc | B / ○ | `[glyph] 取消` |
| 确认覆盖层 | Enter / Space | A / × | `[glyph] 确认` |
| 移动 | WASD | 左摇杆 | 不在常驻 HUD 显示 |
| 镜头 | 鼠标 | 右摇杆 | 不在常驻 HUD 显示 |

- HUD 从 InputMap/重映射服务读取 glyph，不硬编码 `V`、`G`、`E` 或具体品牌按钮。
- 最后一次有效输入决定提示样式；鼠标轻微抖动和摇杆死区噪声不触发切换。
- 键鼠与手柄切换后 100 ms 内替换 glyph，不闪烁、不同时显示两套键位。
- 当前工程尚未配置右摇杆镜头 action；这是“手柄完整核心路径”的实现依赖，不属于 HUD 自行补偿范围。
- Push-to-Talk 默认按住；无障碍设置必须提供 Toggle-to-Talk，二者使用同一语音状态机。

## 视觉与不透明度预算

### 元素预算

| 预算项 | 上限 |
|---|---:|
| 常驻信息簇 | 2（左上目标、左下需求） |
| 默认同时可见 HUD 簇 | 4（常驻 2 + 中心互动 1 + toast 1） |
| 录音时同时可见 HUD 簇 | 3（目标收拢、需求、语音卡；非紧急 toast 延后） |
| 同时循环/脉冲的 UI 元素 | 1；减弱动态模式为 0 |
| 常驻 UI 占屏面积 | ≤ 12%；目标为 8–10% |
| 含情境卡的瞬时占屏面积 | ≤ 18% |
| 非模态卡片覆盖世界中心 40% 区域 | 0% |

### 表面与透明度

- 常驻卡表面：深靛蓝中性色，alpha 0.78–0.86；实际值按背景亮度取能满足对比度的最低值。
- 互动/语音卡：alpha 0.86–0.92，保证中英文和 glyph 在任何昼夜背景可读。
- Toast：alpha 0.90；不可使用完全不透明的大矩形遮挡世界。
- 日切/完成背景遮罩：alpha 0.55–0.68；内容卡不高于 0.94。
- 装饰纹理、扫描线、渐变光：alpha ≤ 0.24，不得降低文字对比。
- 正文与图标允许 100% 不透明；禁用/次要信息仍需满足 4.5:1 或采用更大字号。

任何视觉设计若超过预算，必须先减少元素或合并信息，不能仅缩小字号和间距。

## 转场与动画

| 动作 | 标准动态 | 减弱动态 |
|---|---|---|
| HUD 首次出现 | 180 ms 淡入，位移 ≤ 8 px | 100 ms 淡入，无位移 |
| 目标更新 | 220 ms 展开；完成勾线 300 ms | 120 ms 交叉淡化 |
| 互动条切换目标 | 120 ms 交叉淡化 | 立即替换或 80 ms 淡化 |
| 需求过阈值 | 一次 160 ms 边框扩张 ≤ 4 px | 边框/图标直接变化 |
| 录音状态 | 低幅波形或呼吸点；1.0–1.5 Hz | 静态麦克风 + 计时文本，无循环动画 |
| Transcribing | 低幅三点序列 | 静态时钟图标 + “正在理解” |
| Toast | 180 ms 淡入并上移 ≤ 10 px；淡出 140 ms | 100 ms 淡入/淡出，无位移 |
| 日切 | 1.2 秒色彩擦拭 + 日期；300 ms 后可跳过 | 200 ms 淡出/淡入，可立即跳过 |
| 完成覆盖层 | 280 ms 淡入，内容上移 ≤ 12 px | 120 ms 淡入，无位移 |

- UI 转场不驱动相机，不缩放整个世界，不使用反复弹跳。
- 任意非必要动画不得超过 500 ms；日切除外但必须可跳过。
- 关闭/暂停窗口后恢复时，不重播目标完成或日切动画。

## 日切与完成覆盖层

### 日切覆盖层

- 触发后暂停玩家移动与领域时间，清理非紧急 toast 队列。
- 内容：`第 2 天`、一句不超过 36 个中文字符的情绪/目标暗示；不列任务清单。
- 300 ms 后任意确认键可跳过；减弱动态模式可立即跳过。
- 完成转场后把焦点交回 gameplay，不吞掉仍按住的移动/语音输入。

### 三日完成覆盖层

- 内容层级：`你在异乡有了第一个立足点` → 一句关系回报 → 《异乡人 / Stranger》纵向切片完成。
- 默认焦点：`继续留在聚落`；次操作：`重新开始三日切片`。
- 重开属于破坏性操作，需二次确认；取消返回默认操作，不直接重置。
- 键鼠可点击，键盘 Tab/方向键和手柄方向键/摇杆均可遍历；Esc/B 等同“继续留在聚落”。
- 覆盖层出现时焦点被限制在内容卡内，关闭后恢复到 gameplay。

## 数据与事件边界

HUD 只读取投影并发出玩家意图，不直接修改领域状态。

| 数据 | 所有者 | HUD 权限 | 更新方式 |
|---|---|---|---|
| 日数、格式化时间 | GameState/时间投影 | Read | `state_changed` 或专用时间信号 |
| 目标文本与进度 | 任务系统/GameState | Read | 目标事件；不建议逐帧轮询 |
| food/warmth/energy 与阈值 | 生存系统/GameState | Read | 状态事件，HUD 限频显示 |
| 最近交互对象与动作 | PlayerController/交互系统 | Read | 目标变化信号 |
| 录音/转写结果 | SpeechAdapter | Read | 明确状态与结果信号 |
| toast 内容与 tone | 领域/反馈路由 | Read | `message_requested`；后续改为结构化消息 ID |

建议 UI 发出的语义事件：

| 玩家动作 | 事件 | 载荷 |
|---|---|---|
| 选择互动动作 | `hud_interaction_requested` | `action_id`, `target_id`, `input_device` |
| 开始/结束/取消说话 | `speech_control_requested` | `phase`, `target_id`, `mode` |
| 选择手势 | `gesture_requested` | `target_id` |
| 跳过日切 | `day_transition_skipped` | `day`, `input_device` |
| 关闭完成层 | `completion_dismissed` | `input_device` |
| 请求重开 | `run_reset_requested` | `confirmed` |

玩家可见文本必须由本地化 ID 与参数生成；HUD 不把领域状态写回，也不通过 label 文本解析进度。

## 无障碍

- 遵守 `design/accessibility-requirements.md` 的 Enhanced 等级。
- 正文对表面至少 4.5:1，大号文字至少 3:1；焦点、条形边界和重要图标至少 3:1。
- 需求、结果与警告同时使用图标形状、文字和位置，颜色不是唯一编码。
- 所有玩家可见 NPC 台词和系统音频都有字幕；录音/转写状态不依赖声音。
- HUD Scale 80%–150%，字幕与正文分别可调；150% 时布局换行而不是裁切。
- 提供减弱动态、高对比、字幕背景、Toggle-to-Talk 和完整输入重映射。
- 麦克风权限、硬件或服务不可用时，手势完成路径保持同等任务与关系结果。
- 完成覆盖层具备明确焦点环、确定导航顺序、取消路径和焦点恢复。

## 本地化

- 首发文案至少支持 `zh-Hans` UI；英语原声/玩家转写按原文显示。结构必须允许 `en-US` UI。
- 游戏品牌写法固定为《异乡人 / Stranger》，但不在常驻 HUD 重复显示。
- 目标、toast、提示和按钮使用字符串 ID + 参数；不得把完整句子硬编码在 HUD 脚本中。
- 布局为英文及其他拉丁语言预留 40% 横向扩展；目标允许 2 行，1152×720 或 150% UI Scale 允许 3 行。
- 动作词优先保留，空间不足时先隐藏解释性副句，不隐藏 glyph、“重试”或“手势”。
- 玩家转写以 `听到：“{transcript}”` 呈现；不自动翻译、不修正语法、不改变大小写以伪造识别质量。
- 人名、物品名和目标文本来自数据表；图标中不烘焙文字。
- CJK/Latin 字体回退必须覆盖中文标点、弯引号、数字与常用 IPA 字符；缺字不得显示方框。
- 时间、数字和百分比使用 locale-aware 格式；阿拉伯数字方向在 RTL UI 中保持正确。

## 验收标准

- [ ] 1152×720、1440×900、1920×1080、2560×1080 下，HUD 全部位于 Safe Frame，无遮挡或裁切。
- [ ] 默认探索时只显示日时/目标和需求两个常驻信息簇，常驻占屏面积不超过 12%。
- [ ] 靠近 NPC 后 120 ms 内出现当前输入设备的说话、手势、观察动作；切换输入后 100 ms 内更新 glyph。
- [ ] Listening、Transcribing、Understood、Clarify、Unavailable、Gesture Confirmed 六种语音状态都有明确文字、非颜色图标和可用下一步。
- [ ] 所有 Clarify/Unavailable 状态都能免费重试或用手势完成，且没有扣分、红叉或惩罚性音效。
- [ ] 食物、温暖、精力越过 50/25 阈值时，仅对应行提高权重，并可在无颜色条件下区分。
- [ ] 目标更新、拾取、保存、昏倒和切片完成不会互相遮挡；toast 队列最多两条且重复拾取可合并。
- [ ] 日切可在 300 ms 后跳过；减弱动态模式下没有位移、擦拭、波形或循环脉冲。
- [ ] 完成覆盖层支持鼠标、键盘和手柄；焦点不逸出，关闭后返回 gameplay，重开必须二次确认。
- [ ] UI Scale 150% 时所有关键文案可读，目标不超过三行，重试和手势操作不被截断。
- [ ] 所有正文达到 4.5:1，对焦点/非文本关键图形达到 3:1，并在昼夜与高亮地面上验证。
- [ ] HUD 仅消费领域投影和发出语义事件，不直接修改任务、需求、关系或存档字段。
- [ ] 从场景加载到首个 HUD 稳定帧不超过 250 ms，目标更新反馈从事件到可见不超过 100 ms。

## 依赖与开放问题

### 实现前依赖

1. 建立 UI 视觉规范/Art Bible，确定字体、颜色 token、图标轮廓和外星材料语言。
2. 将玩家可见字符串迁移到本地化资源；当前 `hud.gd` 与领域消息仍含硬编码文字。
3. 增加输入设备监听与 glyph 解析层，不能继续把 `[V]`、`[G]`、`[E]` 写入提示字符串。
4. 补齐手柄右摇杆镜头 action，以及完成层的 UI 导航 action。
5. SpeechAdapter 暴露 Transcribing、Unavailable、Cancelled 等明确状态，而非只用通用 toast。
6. 确认 15 秒录音上限与超时协议；HUD 不展示未经协议保证的假进度。

### 后续设计问题

- 玩家关系语气词是否直接显示，需在首轮试玩中验证是否过度解释 NPC 表演。
- 资源数量是否需要按键展开的轻量背包，不属于本轮 HUD 实现范围。
- Steam Deck 字号与安全区可在 Windows/macOS UI 完成后作为单独平台变体验证。
