# 《异乡人 / Stranger》无障碍要求

> **状态**：Prototype Gate Approved；正式设置页待完成
> **等级目标**：Enhanced Desktop
> **最后更新**：2026-08-10
> **适用平台**：macOS、Windows；键盘/鼠标与手柄
> **范围**：三日纵向切片、HUD、关键语音/手势互动、日切与完成流程

---

## 等级承诺

纵向切片以 **Enhanced Desktop** 为目标：不仅满足基本可读和替代输入，还必须让不使用麦克风、
听不到提示音、无法辨色、需要大字或减弱动态的玩家完成全部核心路径。当前可玩原型已通过
核心路径门禁；正式发布前仍需完成下述设置页与平台人工验收范围。

本等级不宣称完整屏幕阅读器、眼动输入或平台认证级全辅助技术覆盖。这些属于 Full 等级；
当前实现仍需保持稳定 Control 顺序、结构化文案和语义 action，为未来扩展保留边界。

### 完成定义

以下任一项不满足，纵向切片不得标记“Enhanced 合规”：

1. 麦克风关闭或服务离线时无法完成关键任务。
2. 键盘/鼠标或手柄任一输入方式无法独立完成三天主路径。
3. 颜色、声音或循环动画关闭后，关键状态无法理解。
4. 150% UI Scale 或 1152×720 下关键操作被裁切。
5. 语音未识别导致需求、资源、关系、任务或存档损失。

### 当前原型门禁与正式版待办

2026-08-10 的 Art、UX 与 Accessibility 联合复核确认：键鼠/手柄核心 action 重映射、
模态焦点闭环、80%–150% HUD Scale、Reduce Motion、Hold/Toggle-to-Talk、无麦克风手势替代、
中英文字符串、非颜色语义图标及无惩罚语音恢复均已达到纵向切片原型门槛。

以下项目可延期到正式设置页，不阻塞当前原型测试，但在宣称完整 Enhanced Desktop 支持前
仍必须完成：High Contrast HUD；独立 Text/Subtitle Size 与字幕背景强度；Transcript、数字需求
和消息持续时间选项；手柄死区与键鼠/摇杆灵敏度；Camera Shake、Motion Blur；完整音频、字幕、
语言设置；单项恢复默认、设备拔插与平台人工验收矩阵。

---

## 原则

- **同等完成，不是安慰奖**：手势替代得到相同任务与关系结果。
- **多通道反馈**：关键事实至少通过文字 + 形状/图标表达；适当再加音频或震动。
- **低羞耻语言**：只描述系统是否理解意图，不给玩家打语法、口音或发音分。
- **可调整而非猜测**：字号、HUD Scale、字幕背景、动态、按住/切换说话均由玩家设置。
- **世界与 UI 双保险**：世界表演是主要反馈，HUD 确保玩家不会因感官差异漏掉结果。

## 键盘、手柄与焦点

### Gameplay HUD

- 常驻 HUD 不取得 UI 焦点；世界 action 直接由 InputMap 处理。
- 临近互动提示显示 action，但不把焦点从玩家控制器移到 Control。
- 输入方式切换必须保留同一交互目标和语音状态。
- 当前原型缺少右摇杆镜头 action，补齐前不得宣称手柄完整支持。

### 模态覆盖层

- 默认焦点落在最安全的可逆操作。
- 键盘 Tab/Shift+Tab、方向键、手柄 D-pad/左摇杆均有确定顺序。
- Enter/Space 与 A/× 确认；Esc 与 B/○ 取消。
- 焦点环厚度至少 2 px（按 UI Scale 缩放），与相邻表面至少 3:1。
- 关闭时吞掉同帧输入并恢复 gameplay；不允许焦点留在已隐藏节点。

### 重映射

- 每个核心 action 至少允许一个键盘和一个手柄绑定。
- 冲突检测按上下文判断；同一 gameplay 上下文的冲突必须提示。
- 不能解除“确认”和“取消”到完全无绑定；需要先提供替代绑定。
- 提供“恢复全部默认”和单 action 恢复，破坏性恢复需确认。

## 动态减弱规则

Reduce Motion 开启后：

- 所有 HUD slide/scale/wipe 改为 80–120 ms crossfade 或立即替换。
- 录音波形、呼吸点、需求脉冲、三点等待动画全部停止。
- Listening 使用静态麦克风 + 录制点 + 数字计时；Transcribing 使用静态时钟 + 文本。
- 日切使用最多 200 ms 的淡出/淡入，无径向擦拭，可立即跳过。
- 完成层只淡入，不移动内容卡。
- UI 不触发相机位移、FOV 拉伸、景深焦点扫动或全屏色差。

无论设置如何，任何可见内容都不得以超过 3 次/秒的频率闪烁。

---

## 本地化与语言可访问性

- 玩家 UI 语言与说出的英语分离：说明和反馈本地化，原始转写保留英语。
- 目标、提示、toast、字幕、按钮全部来自字符串 ID 与参数；不可由脚本拼接固定中文句子作为最终实现。
- 布局预留 40% 文本扩展；中文断行不能把人名、数字进度或 action glyph 单独留在下一行。
- 不把语法术语作为完成任务所需知识，不要求玩家理解“宾语”“时态”等教学标签。
- 示例说法如果出现，标记为“可以这样说”，并提供多个意思等价的短句；不能展示唯一标准答案。
- Transcript 关闭时不影响手势路径、状态理解和 NPC 字幕。
- 字体回退覆盖简体中文、ASCII、弯引号、重音拉丁字符和常见 IPA 字符。

## 测试矩阵

### 分辨率与视觉

- 1152×720，UI Scale 100% 与 150%。
- 1440×900 参考画布，日/夜两种背景。
- 1920×1080 与 2560×1440。
- 2560×1080 超宽屏 Safe Frame。
- 灰度、deuteranopia、protanopia、tritanopia 模拟。
- 默认与 High Contrast HUD。

### 输入

- 仅键盘/鼠标完成三天。
- 仅 Xbox 布局手柄完成三天。
- 通用/PlayStation glyph 映射检查。
- gameplay、录音、Transcribing、模态层期间热切换设备。
- Hold 与 Toggle 两种说话模式。
- 重映射、冲突、恢复默认、拔出手柄后继续。

### 语音与替代

- 麦克风权限允许、拒绝、运行中撤销。
- 服务正常、未启动、超时、返回无效 JSON。
- 空录音、短录音、15 秒上限、取消、离开 NPC 范围。
- 三次连续未识别后仍可重试，并能用手势完成。
- 每个失败路径前后比较需求、资源、关系、任务和存档快照。
- 全局静音、Transcript Off、Reduce Motion On 下完成核心交流。

### 焦点与时序

- 日切跳过不会立即触发世界互动。
- 完成层焦点不逸出；Esc/B 返回，重置需确认。
- 窗口失焦/恢复不会重播奖励、重复提交语音或丢失焦点。

## 当前实现差距

以下为规范产出时已知差距，不代表规范降低承诺：

1. `hud.gd` 仍使用硬编码中文、固定像素位置和永久帮助文字。
2. 语音的 Listening、错误和完成状态目前共用通用 message toast，缺少独立状态卡。
3. 没有 UI Scale、字幕、高对比、Reduce Motion、Toggle-to-Talk 或消息时长设置。
4. 没有输入重映射界面与设备 glyph 服务。
5. InputMap 尚无右摇杆镜头 action，手柄无法独立完成完整移动/观察路径。
6. 没有完成覆盖层焦点管理和重置二次确认。
7. 玩家可见字符串尚未迁移至本地化资源。

这些差距在 UI 实现和无障碍复核阶段逐项关闭；任何 Blocker 未关闭时，最终评审结论必须为
NEEDS REVISION，而不是以“原型阶段”为由跳过。
