# AAA 聚落环境研究：视觉与数据双角度比对（对标 art-bible v1.4）

*Created: 2026-08-14*
*用途：防止《异乡人》聚落美术风格跑偏的对照基准。分析对象为公开发售的 3A 游戏宣传截图/wiki 截图，版权归原厂商，仅作内部风格研究。*

---

## 0. 方法与口径

- **视觉分析**：qwen3.7-plus 视觉模型按统一五维评审口径（构造接缝 / 接触接地 / 材质家族 / 使用痕迹 / 地面路径 + 工艺信号 TOP3）逐张分析，评审词与 `design/art/art-bible.md` v1.4 的四信号框架（§1.4、§3.6、§5、§8.8）一一对应。
- **数据角度**：从各案例提取可测量项（材质家族数、地表层数、主路宽/房高比、痕迹计数、构造单元清单），再与 Sketchfab 高精度复刻、GDC 演讲等公开数据交叉印证。
- **图片归档**：沙箱网络禁止二进制下载，图片以远程 URL 归档（Wikia CDN 带 `cb` 时间戳的 URL 长期稳定），清单见附录 A。qwen 视觉插件可服务端直读这些 URL，后续随时可复查。
- **案例谱系**：刻意覆盖 风格化（Zelda ×2）→ 半写实部落（Horizon）→ 写实（Witcher 3、RDR2），并含一张俯瞰图补"聚落布局"维度。本作为风格化档，主要对标 Zelda/Horizon，写实案例只取工艺原理不取画面参数。

**跨案例不变量（5/5 案例全部命中）：**

1. **地表恒为 3 层**：踩踏/车辙带 → 压实或稀草过渡带 → 植被边。无一例外。
2. **接触阴影 100% 明确**：柱根、底脚、桶箱全部有深色 AO/闭塞阴影，无一悬浮。
3. **材质家族 4–6 种/镜头**：靠受光差异（漫反射强弱、高光锐度、明度）区分，不靠贴图花纹。
4. **痕迹 ≥5 处/镜头**：且痕迹有行为逻辑（货堆在门口、马拴在桩上、路通向每户入口）。
5. **构造可数、模块化+非标变体**：标准件拼装，但用错位/加建/混合材质打破重复感。

## 2. 视觉证据要点（按案例）

### 2.1 BotW 卡卡利科村（本作最直接的对标）

- **构造**：栅栏 = 粗木桩 + 细木条穿插，桩顶有截面厚度；门洞/圆窗边缘有深色内退面（墙体物理厚度）；茅草屋顶边缘有木质屋檐托底（茅草层与木构层的层叠接缝）。
- **接触**：树根有地形微隆起 + 泥色过渡（"扎根"感）；建筑底木构直接压在草地上并有阴影过渡；水边岩石半掩埋。
- **家族受光**：木 = 暖棕漫反射；茅草/植被 = 高漫反射无高光；石 = 灰白 + 硬明暗交界；织物 = 高饱和薄透；水 = 镜面。
- **痕迹**：绳晒衣物、围栅翻耕田 + 幼苗排、木水车、主干道红色幡（导航道具）、踩踏磨损土路。
- **工艺 TOP3**：① 模块化资产 + 变体替换（少数基础件量产全村）；② 接地融合 + AO 烘焙（资产"长"在地上而非"放"）；③ 功能性资产与叙事性道具分层布景。

### 2.2 TotK 卡卡利科村（重建期 = 本作 D2/D3 跨日状态的参考）

- **构造**：弧形陶壳上下两半拼接、中缝明确；木栈道板缝清晰；日式屋顶飞檐出挑 + 柱支撑。
- **接触**：大壳体底部深色闭塞阴影交代重量感；部分建筑石质/木抬高基座隔潮；裸露脚手架 = "仍在建造/维护"的可读状态变化。
- **家族**：石陶壳 / 木 / 金属连接件 / 植被，4 种即够读。
- **痕迹**：檐下灯笼、平台角落箱桶、木架彩布条、建筑间泥路、脚手架。
- **工艺 TOP3**：① 标准件 kitbash（弧壳 × 尺寸档 + 标准栈道长度）；② 建筑嵌山体 + 前景植被遮边（景深与引导）；③ 灯笼/货箱/旗帜等叙事道具打破模块重复。

### 2.3 Horizon 母亲升天村（绳结棚屋 = 本作"纤维绳结"家族的直接参照）

- **构造**：粗原木立柱横梁 + 每个交叉点的 X 型/环绕型**蓝色绳绑扎**（3D 细节而非贴图）；茅草/木板混屋顶 + 图腾布。
- **接触**：两种接地逻辑并存——高塔主柱**插入泥土**（深固定感）、矮棚与箱**垫在扁平石块/垫木上**（防潮生活逻辑）；AO 深邃"钉"在地上。
- **家族**：原木/织物绳索/茅草/岩/积雪，靠粗糙度差 + 织物薄边 SSS 区分。
- **痕迹**：塔上守望 NPC 剪影、塔底篝火、储物木箱、立柱图腾印花布、一层横梁草垫、屋顶茅草不齐 + 积雪厚度不均（风化）。
- **工艺 TOP3**：① 受力逻辑拼接（立柱承重→横梁→绳固定→覆盖层）；② 高饱和派系色织物做"材质叙事"视觉破局点；③ 分级接地（入土 vs 垫石）+ 积雪自然过渡。

### 2.4 Witcher 3 白果园（俯瞰 = 布局与分区数据源）

- **布局**：建筑顺应地形与主路**错位散点**排布，非网格；附属建筑依主屋"加建"；居住区（密）与农仓区（疏、贴农田）分区明确；围合中心留水井/聚集空地。
- **接触**：俯瞰下建筑靠底部一圈阴影 + 石基/垫木厚度避免"纸片贴地"。
- **地表**：车辙交通带（最浅最裸露）→ 路缘稀草带 → 草地，另有规则耕地块；河岸有渡口浅滩。
- **工艺 TOP3**：① 高度/斜率驱动的地形材质混合（水→沙→泥→耕→草无缝过渡）；② 非网格散布打破复制感；③ 全局 AO/光照烘焙让独立模型在宏观视角融为一体。

### 2.5 RDR2 瓦伦丁（写实上限参照，只取原理）

- **构造**：旅馆 = 木骨架 + 水平墙板 + 层叠瓦顶 + 双层门廊（可分离附加层）+ 烟囱；仓库 = 金属波纹板顶 + 木板墙，板间深色接缝线；侧屋加建 = 不同材质拼接的"扩建史"。
- **接触/地表**：车辙不仅变色还**物理凹陷**（几何级磨损）；主街 U 型分层：中央泥泞车辙带（积水反光）→ 两侧压实人行带 → 外缘杂草。
- **痕迹**：招牌、拴马桩拴马、店门货堆、交错车辙马蹄印、营地晾晒锅椅、加建拼接、路边废板。
- **工艺 TOP3**：① Decal 贴花系统（车辙/泥泞/干湿过渡叠加在地形上）；② 模块"非标准化"拼装（错位 + 非对称附属 + 混合材质 = 有机生长）；③ 高密度叙事道具按行为逻辑摆放。

## 3. 与美术圣经 v1.4 条款的映射核对

| 圣经条款 | AAA 证据 | 核对结论 |
|---------|---------|---------|
| §3.6 材质家族 ≤3/英雄资产、主家族 ≥60% | 每镜头 4–6 家族是**全镜头**计数（含地形、植被、道具）；单个英雄建筑本身仍是 2–3 家族（BotW 茅屋 = 木+茅草；Horizon 塔 = 木+绳织物） | ✅ 一致，无需改。验收时按"英雄资产本体 ≤3"执行，全镜头家族数只作读图参考 |
| §3.6 灰阶可分 | 家族靠受光差异（漫反射/高光/明度）区分，不靠花纹 | ✅ 一致。5 案例的区分手段全部是受光属性 |
| §5.2 密度（核心 4×4m ≥1 中型道具） | RDR2/Valentine 与 BotW 村落道具密度远高于此 | ✅ 纵切片门槛合理，D1 验收后可按试玩反馈上调 |
| §5.3 构造清单（门洞厚度/板缝/基座） | 门洞内退面、桩顶截面、屋檐托底、石基隔潮在全部地面视角案例中 100% 出现 | ✅ 一致。补强建议：加入"两种接地逻辑"（插入 vs 垫基）作为 §5.3 可选项，Horizon 证明混用能显著提升可信度 |
| §5.4 三层地表 | 5/5 案例恒为 3 层 | ✅ 强一致。补强建议：主街可加"U 型"变体（中央车辙/通行带更裸露 + 两侧压实人行带），见 §4 |
| §5.5 痕迹词汇表 | 每镜头 ≥5 处且遵循行为逻辑（货在门口、路通每户） | ✅ 方向一致。圣经"英雄资产 ≥1 处"是下限；建议市场核心镜头按 ≥5 处自查（§8.8 第 5 项已含 NPC 驻点 3 证据，够用） |
| §8.8 验收清单 | 四信号 + 三层地表 + 跨日状态全部有 AAA 对应物 | ✅ 可执行。跨日参照 TotK 重建期（脚手架/半成品状态）与 RDR2 加建逻辑 |
| §1.4 剪影（活泼/亲切/陌生） | Zelda 幡与灯笼、Horizon 图腾布 = 高饱和小面积"破局色"引导 | ✅ 一致。本作"陌生感"细节可借用 Horizon 派系色做法：每个 NPC 驻点一个小面积高饱和识别物 |

**结论：v1.4 条款与 AAA 证据无冲突；有两处可补强（见上表），已按"建议"列出，不强制改圣经。**

## 4. 对本作的量化基准（从数据汇总直接推导）

聚落核心（市场带）验收自查数值：

1. **主路宽/房高比 40–70%**。Zelda 地面村 50–60%，Horizon 60–70%；低于 30% 会拥挤（TotK 山地村 30–50% 是坡地特例），高于 100% 只有写实主街才成立。本作市场主街建议取 **50–70%**。
2. **地表恒 3 层 + 弯月磨损带**（§8.8 已有 ≥2.5m/12m 可读要求，不变）；主街可选"中央更浅的通行带"变体。
3. **英雄建筑本体 2–3 家族**，其中主家族 ≥60%（§3.6 不变）；全镜头读图家族数按 4–6 自查，低于 3 = 场景过素。
4. **痕迹密度**：市场核心镜头 ≥5 处生活痕迹且各有行为逻辑；每个 NPC 驻点 ≥1 个小面积高饱和识别物（对应 Horizon 图腾布 / Zelda 幡）。
5. **接地二选一或混用**：柱脚要么插入地面（+根周微隆起/泥色过渡），要么垫石/垫木；任何"悬空平面直贴地"都按 §5.1 积木判定退回。
6. **模块化 + 非标变体**：同一构造件在场景内至少出现 1 次旋转/错位/材质混合变体，避免等距网格复制感（全部 5 案例的共性工艺）。

## 附录 B：方法备注
