# R-36 配色补充 — 温暖、柔和的 2D 阅读界面

对应 FR-47 的用户补充要求：配色要有高级、柔和感，支持愿意继续停留的体验。视觉方向采用暖纸白与植物色，降低深绿和亮黄的大面积对撞；没有把视觉判断当作已验证的留存提升。

| 用途 | 颜色 |
| --- | --- |
| 主面板 / 对话纸面 | `#F3EFE5` / `#FAF6EE` |
| 正文 / 次要文字 | `#38433C` / `#626C61` |
| 选中项 / 主操作 | `#DCE4D6` / `#59705E` |
| 少量黄铜棕 / 正向反馈 | `#80664C` / `#496B59` |

统一覆盖顶栏、地点菜单、状态条、对话框、玩家字幕、行囊、柜台、住处、成长、历史、设置、按键重映射及提示。图标使用低饱和棕、灰绿与橄榄绿；原有不同轮廓保留。主要行动用鼠尾草绿，柜台次要“现在吃”保留浅底，避免两个强按钮争夺注意。面板用暖灰阴影和较轻遮罩，人物与背景保留自身画风；场景上的文字仍使用暖白和暗影。

配色集中在 `game/scripts/novel/novel_palette.gd`。按钮选中态保持与常态相同的内边距，切换分类不会改变按钮宽度；键盘焦点不再用不透明底色覆盖主按钮，绿色主操作采用内嵌纸白焦点框。3D 的物品图标默认颜色未改，2D 通过实例属性指定颜色。

验证证据位于 `docs/reviews/soft_palette_2026-09-11/`：

- `contrast.json`：正文 8.98:1、次要文字 4.77:1、主按钮文字 4.99:1；检查的 10 组文字组合均 ≥4.5:1。普通按钮焦点相对纸面 4.07:1，主按钮内框 4.99:1。该数值针对色板中的背景组合，背景插画上的文字另以实渲染检查。
- `runtime.log`：原有行囊、物品操作、真实鼠标遮挡、Tab 焦点、九段日常及小窗口回归通过。
- `novel-regression.log`：语音播放结算、旧档迁移及三夜流程回归通过。
- `bag.png`、`counter.png`、`confirmation.png`、`full-counter.png`、`primary-focus.png`：正常/选中/禁用/确认与焦点实际渲染。
- `day-scene.png`、`night-scene.png`、`settings.png`、`remap.png`、`bag-1152.png`：白天、夜间、大对话字号与 1152×720 的实际窗口检查。
- `export.log` 与 `export-smoke.log`：macOS 2D Novel 重新导出，并启动独立二进制检查资源和脚本加载。

这次仅调整表现层；口语评分、物资规则和存档格式沿用现状。桌面包在 `build/novel/Stranger2D.app`，可通过 `game/run_novel.command` 启动。
