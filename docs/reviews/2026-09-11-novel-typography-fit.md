# R-36 字体与交互补充 — 视觉小说的阅读层级

对应 FR-47 用户补充要求：字体与 UI 边框更加优雅，参照 galgame 的交互方式。沿用已确定的暖纸白、低饱和鼠尾草绿与黄铜棕，重点调整阅读节奏和控件层级。

## 实现

| 层级 | 最终处理 |
| --- | --- |
| 叙事 | Noto Serif SC 400 对白，标准 26px / 大字号 30px；标题和姓名 500。中文与英文由同一字体覆盖。 |
| 操作 | Noto Sans SC 正文 400、按钮 450，代替所有文字一律 500 的设置。 |
| 对话框 | 轻纸面、独立姓名牌、细黄铜线与内侧分隔线；阅读区域扩大为 1048×142，操作区位于独立底栏。 |
| 导航与行囊 | 顶部导航和辅助动作采用透明常态；地点、物品以左侧细线和浅绿底选中；分类以底线选中，保持各状态内边距一致。 |
| 边框 | 主面板 6px、按钮 4px、姓名牌与导航 3px 小圆角；次要按钮只保留下方细边，键盘焦点保留完整可见框。 |
| 主操作 | 录音放在右端，交谈、手势和柜台在左侧；重听与开口灵感保持可达。小剧场右端主操作先显示全文，再下一句，最后回到现场。 |
| 文字与焦点 | 实时交谈的「显示全文」只补全文字，完成后若该控件持有焦点，则交给录音；长回应可滚动，新回应回到顶部，保留文本选择。 |

状态条恢复为实际 6px 高度，解决加入主题前被默认字体最小尺寸撑高的问题。切换场景时先重置人物透明度，再按动态偏好淡入，避免减少动态时保留半透明人物。

字体与许可位于 `game/assets/fonts/`；新增字体来自 Google Fonts，数据未修改，许可为 OFL 1.1。预设明确包含新字体及两种字体的许可文本，导出日志已确认这些文件打入包内。来源、字重与 SHA-256 记录在字体目录的 README。
