# 主动开场与话题深度 · 2026-09-14

## 需求对照与根因

PRD FR-38 已要求地道开场和延伸多轮对话，FR-48 要求校园情景、历史和已知记忆支持持续交流。此前的状态机/录音通过不等于内容体验达到要求。

Mira 虽已接入模型，仍沿用柜台 30 词/2 句规则。实时路径只提交首句，后续观点和接话点没有进入实际字幕和 TTS。校园有场景和记忆，却仍要玩家先发言。角色也容易反复提问、泛泛安慰或编造眼前景物。

## 本轮变更

- Mira 使用独立社交提示与 60 词/3 句上限；完整回复统一提交字幕和 TTS。服务柜台仍保持原短句、具名成交和播放结束结算规则。
- 社交回复先回答当前话意，再贡献相关观点、理由或例子。上一轮已经问问题时，下一轮先分享而非连续盘问；检查已观察到的无依据场景描述，并允许最多两次重写。模型失败如实返回，不用欢迎语代替。
- Mira 在正常进入/继续场景时可主动开场，每个游戏日只成功主动开场一次，状态随本地存档保存。取消/忙碌时不插话。
- 校园进入新情景后由一位 NPC 根据情景和知情记忆开场；已有历史不重新开场，住处、柜台、录音/播放和模态面板期间不触发。多人回复要求第二位补充观点而不是重复赞同或再次盘问。
- 开场具有独立来源：不伪造玩家历史、不计玩家成绩/词汇 used、不发物资，也不结算校园社交奖励。
- 告别和换题得到尊重。PRD 已补充独立的内容体验验收条款。
