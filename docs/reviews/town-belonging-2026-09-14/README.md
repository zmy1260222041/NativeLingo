# 异乡人逐渐认识小镇社会 · 2026-09-14

## 方向修正

之前的内容优化偏向通用闲聊。本轮依用户明确要求，把小镇对话组织为：陌生人找到落脚点，通过具体生活来往认识不同居民，再成为可被认出的熟面孔。设计约束见 `design/quick-specs/town-belonging-2026-09-14.md`，PRD 同步补充。

五个角色的服务端资料新增独立态度、贡献、已知人物事实和个人立场：Mira 热情牵线，Tavi 忙碌务实，Ori 客气有距离，Vesh 冷淡重实际问题，Rowan 寡言重邻里互助。没有把所有人改成导游，也没有新增游戏世界不存在的地点、官方政策或任务。

## 实现

- `town_context.py` 只整理当前 NPC 的已完成交流数、见面天数和相关确证事件。0 次为初见；有来往为再次相见；至少 4 次交流且跨至少 2 天为熟面孔。这只是认出对方，不修改原关系值、任务或奖励，更不自动成为好友。
- 交流和双方原话只在对应回复真实播放完成后写入 2D 独立存档；每 NPC 保留最多 8 条，重新开会话可接续。仅开场不加次数，失败/取消不加次数，其他 NPC 和校园不共享这段历史。
- Mira、Rowan 使用社交开场与连续回复；开场根据初见/回访阶段选择方向。交谈按钮不再绕回固定欢迎语。
- 店员在非订单交流中保留完整短回复；不能因清理不可靠商品说法，只剩一声欢迎。真正订单仍走原具名成交和音频完成结算，不附加社交条件。
- 指引有节制：初次落脚、问路或具体需求可介绍一个合适的人；普通聊天留在当前话题，不能机械派发下一站。不得替另一居民保证帮助或透露未知私事。
- Rowan 只在本地确有 `help_rowan` 事件时知道已送水；持有可送水物品时，原手势动作明确标为“送一份水”。聊天既不消费物品，也不编造送水。

## 发现后再修的偏差

首次同题测试 Ori 仅剩欢迎语；完整回复清理掉不可靠商品位置后，原先没有补足内容。现非订单指引有完整回复校验和有限重写。初版的实体关键词检查又误拒了有效 burger/taco 指引，已移除该过窄条件，保留失败日志。

第一次语音测试 Mira 仍会在普通聊天后推荐别人，并称 Rowan 总会帮忙；随后增加当前话题的推荐限制与他人承诺检查，再跑最终语音测试。旧 `voice.log`、`live-before-guidance-repair.json`、`live-repair-failure.log` 留作追溯，不能作为最终无问题证据。

范围：这是既有小镇篇章的叙事和来往记忆增强。原三夜结束条件仍在，未扩成无限长期城镇模拟；模型对话品质仍需持续试玩，不能声称所有话题都已通过。
