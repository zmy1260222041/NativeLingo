# R-37 / FR-48：校园篇章

## 已确定规则
独立美国本科校园篇章；可配置档案；生存养成与社交压力；学业为轻量完成度；持续生活、按周回顾。
社交 -2/游戏小时；低于 25 的实际时间精力额外 -4/小时；交流 +8、共同活动 +16、人物每日上限 24。
每周五次课堂和五次自主学习，各 +10。阅读、等待和失败零时间、零结算。

## 验收门
- G1：32 情景、8 角色、8 连续事件，全部可达，三种关系变体与可选档案。
- G2：多人身份、顺序发言、长对话与知情者隔离；更正/删除记忆；迟到响应隔离。
- G3：阈值跨越、每日限额、活动幂等、周结算、独立存档及两周养成模拟。
- G4：录音、配音、文字和离线活动；不伪造语音反馈；餐饮延续具名成交。
- G5：四类真实模型各八次玩家发言及美国 TTS；记录失败，不以 stub 替代。
- G6：原小镇回归，长文字、小窗口、多角色与桌面截图，独立导出。

## 实施证据
首轮审查：基础功能原型，尚未验收通过。校园本地 105 项断言、Python 9 项契约测试通过；四类真实模型记录仅课堂 8 轮、社团 1 轮、吃饭 6 轮、运动 0 轮，`live-dialogue.json` 为失败。原小镇 NovelTest / NovelInteractionTest 回归通过。首轮程序几何美术不满足原小镇插画完成度，独立应用尚未包含校园。

## 本轮改进验收（实施前固定）

1. 沿用小镇的插画舞台、人物立绘、纸面对话与导航层级；保留全功能的 960×640、1152×720、1440×900 画面证据。最终美术资源不足须明确记录，不能以占位图冒充通过。
2. 32 情景有独立目的、关系变体、退出和完整示范；八条连续事件有跨日语境。档案匹配观察内容而非仅判断非空，经历练习可编辑且不发送完整日记。
3. 原话来源、NPC 约定、未完成话题及当前会话可存读；更正/删除清除旧上下文；知情者隔离经过多人和跨日测试。
4. 每周两类学习各最多五次、每天同类一次，周末可补；正常通勤与实际最低具名补给路径的两周模拟可持续。
5. 四类模型各八次玩家发言真实运行成功；长度、重复答复、配音和错误重试实际记录。八条跨日承接使用真实模型，修改和删除记忆后验证旧信息不再出站。
6. 重跑小镇、校园与交互回归；导出新应用、确认校园资源在包内，启动导出后二进制。

程序、内容与界面统一已完成本轮验收；最终插画资源尚未完成，不能将整体美术标记为通过。

本机语音服务已重启加载新实现，`local-service.json` 记录 Gemini ready 与 xAI us-east-1 配置。发布二进制不允许命令行覆盖场景路径，最初的两次指定场景尝试因此中止，日志保留。改为直接启动发布二进制的默认小镇入口，并以完整 Godot 引擎加载同一发布 PCK 内的校园场景作加载冒烟；均未执行玩家行动。发布包的校园资源路径亦已检查存在。

剩余验收：生成并接入六处校园背景与八名成年角色立绘，检查构图、角色区分及长对白遮挡，再重新导出。用户随后已明确授权图像 API 替代路径；本机当前环境缺少 `OPENAI_API_KEY`，已请求用户在本地配置，尚未调用生成服务。14 份独立提示词与文件清单已准备，详见美术制作说明。
