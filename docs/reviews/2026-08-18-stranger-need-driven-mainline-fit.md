## 2. 与既有约束的冲突与解决

| 既有约束 | 本次变化 | 解决方式 |
|---|---|---|
| FR-28 §4.1 三日指定供给者顺序 | 该顺序把外星炉/合金/送水当成主线,不符合 FR-21 日常第 1 层 | FR-42 取代该任务日历;FR-28 只保留「交流换物资 + 分档」 |
| FR-41 便利店第 3 天、零件第 2 天才开 | 渴了必须等到第 3 天,仍是任务锁 | 服务点全天开放 |
| FR-30 引导含问候米拉再求食 | 引导仍可教开口,但不能变成主线门 | 跳过引导后立即按需求去店;未问候也可成交 |
| 无语音构建完整可玩 | 通关不再走罗文送水 | `gesture_fallback` 买食物/买水 + 三次过夜即可结束竖切 |

## 3. 门控判据(实现前写死)

- **G1 服务点不按日历上锁**。`can_start_service_dialogue("tavi"|"ori")` 在第 1 天、未问候米拉时为 true。向奥里买水不要求 `day >= 3`。
- **G2 目标由需求驱动**。`food` 低于舒适线时目标指向食物店;`energy` 低于舒适线且食物已舒适时目标指向便利店。目标不得再要求「先找米拉 / 修加热器 / 给罗文送水」。
- **G3 睡觉不绑任务清单**。未问候、未修炉、未送水时,只要到夜晚或精力过低即可睡。引导进行中仅在 `sleep` 步允许睡。
- **G4 三晚结束竖切**。连睡 3 次后 `game_finished`;不要求 `heater_repaired` 或 `help_rowan`。罗文送水可保留为可选,不触发通关。
- **G5 资源仍语音门控**。`interact("berry"|"scrap"|"water")` 不改变资源;食物/水只经 NPC 语音或 `gesture_fallback`。
- **G6 无语音三次过夜可结束**。`web_beta_no_voice` / `desktop_beta_no_voice` 用 `gesture_fallback` 买一次食物、买一次水、睡 3 晚即可 `game_finished`。顺序不限。
- **G7 回归**。`test_game_state`、`test_voice_gated_rewards`、`test_onboarding`、无语音套件、`test_npc_dialogue_assets` 按新主线更新后全绿。

## 4. 设计基线

本轮第 1 层现代实现:

| 需求 | 社会实现 | 服务点 |
|---|---|---|
| 饿 | 柜台点餐 | 塔维食物柜台 |
| 渴 / 精力低 | 便利店买水或饮料 | 奥里便利店 |
| 睡 | 天黑或太累回住处 | 庇护所 |

维什零件前台与加热器留在世界,不进入目标或通关。

## 5. 非目标

- 不重做美术或搬迁 NPC。
- 不改变 Grok 对话契约。
