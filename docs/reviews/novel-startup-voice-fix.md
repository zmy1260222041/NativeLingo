# 启动、新手引导与开场语音修复

用户反馈：双击 run_novel 直接出现在 Tavi 餐摊，没有从头开始的引导，开场文字无声音。

## 原因与修复

- 本地 2D 存档已保存 food 地点和 guide_seen=true，旧启动流程无选择地自动恢复。增加继续/从头开始菜单，禁止 Esc 绕过选择。从头开始先备份当前 2D 存档，再清理旅程的展示状态、重置到第一天广场并打开引导；备份失败不重置。退出启动菜单时不保存。
- start/travel 原本只调用 say 更新文字。现在使用服务端已有白名单 ID 播放五名角色开场白，文字与语音内容一致；请求可重听，失败给出明确提示。启动选择或引导显示时不抢先播放，进入游戏后才播放。
- 首次引导完成后从广场认识 Mira，不再直接跳至 Tavi。已有词汇继续遵循原重开规则保留。
- 独立导出包实机启动复验发现卡在 AudioDriverCoreAudio::init_input_device，macOS CoreAudio 等待尚未解决。开发目录启动器改为优先用本机 Godot 运行源码，避免该导出包启动路径及旧包问题；无引擎时保留导出包后备。此项是可用开发启动路径，不宣称已修复独立包的系统设备初始化问题。

## 验证

- NovelTest 通过，新增启动菜单不可绕过、继续保留地点、从头开始清理引导标记、完成引导播放 Mira 欢迎语的检查；原三夜与存档回归通过。
- Python 132 项通过，包括五条开场文字与服务器配音目录一致性。

- 已实际运行 run_novel.py 打开当前源码游戏窗口。导出成功，但独立包 GUI 启动仍有上述设备初始化限制。
