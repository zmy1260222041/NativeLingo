# FR-44 物品界面 UX Review

日期：2026-09-07  
评审对象：`design/ux/item-usage.md`、`game/scripts/item_panel.gd`、`game/ui/item_glyph.gd`  
依据：`design/gdd/item-usage.md`、`design/art/art-bible.md` §6  
结论：**APPROVED（垂直切片可玩品质）**

## 结论摘要

初检为 **NEEDS REVISION**：旧面板使用四角同圆的 `StyleBoxFlat` 外框，与 Art Bible 的折片墨线框冲突；
标题、容量、条目、详情和动作视觉权重接近；条目只有文字；少量物品时存在无意义空白；焦点没有明确闭环，
世界交互提示与全局 toast 还会在面板后方竞争注意力。

本轮已逐项修复。复核画面中，外框、信息层级、类别剪影、选中态、主次动作和背景反馈的关系清楚，
1152×648 / 150% 下可滚动且未裁切。没有阻塞实现或可用性的 P0/P1 问题。

## 检查结果

| 检查项 | 结果 | 证据 |
|---|---|---|
| 视觉整合 | 通过 | 外层改为 `SiltInkPanel`，保留右上折角；短织带只承担层级锚点 |
| 信息层级 | 通过 | 标题/用途副标题/容量/列表/详情/反馈/动作顺序固定，详情使用独立深色承托卡 |
| 条目辨识 | 通过 | 食物开口种荚、饮品瓶形、住所承托槽三种不同轮廓；选中态还有左侧实体色带与 3 px 焦点框 |
| 交互与输入 | 通过 | 主/次/整批动作仍使用 InputMap；关闭按钮、键盘和 D-pad 焦点全部留在面板内 |
| 空与错误状态 | 通过 | 空、容量、不安全、位置错误、浪费确认、stale、完成均有可恢复文案；失败不消耗物品 |
| 适配与无障碍 | 通过 | 90%×75% 尺寸预算；150% 时三行窗口滚动；至少 44 px 关闭目标；颜色不是唯一线索 |
| GDD 一致性 | 通过 | 食物/饮品现场用或带走；日用品住所先放后用；UI 不写入词汇库状态 |
| 数据责任 | 通过 | 实例、revision、效果继续由 `GameState.items` 权威拥有，界面只提交命令并展示结果 |
