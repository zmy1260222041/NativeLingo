# Stranger 2D 字体

界面操作使用 Noto Sans SC（正文 400、按钮 450）；叙事标题和姓名使用 Noto Serif SC 500，对白使用 Noto Serif SC 400（标准 26px、大字号 30px，基于 1440×900 画布）。两种字体均随游戏离线提供，许可随 `macOS 2D Novel` 导出。

- Noto Sans SC：保留已有 `NotoSansSC-Variable.ttf` 与 `OFL-NotoSansSC.txt`。
- Noto Serif SC：2026-09-11 从 [Google Fonts 的 Noto Serif SC 目录](https://github.com/google/fonts/tree/main/ofl/notoserifsc) 获取原始可变字体 `NotoSerifSC[wght].ttf`，本地文件名为 `NotoSerifSC-Variable.ttf`，字体数据未修改。许可为 SIL Open Font License 1.1，全文见 `OFL-NotoSerifSC.txt`。
